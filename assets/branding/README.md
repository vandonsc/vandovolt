# Identidade visual do VandoVolt

- `vandovolt-mark.png`: marca principal com fundo transparente.
- `vandovolt.ico`: ícone do aplicativo em 16, 24, 32, 48, 64, 128 e 256 pixels.

A marca combina um **V** geométrico com um raio. Os ícones de mouse, headset e o painel flutuante permanecem inalterados.
